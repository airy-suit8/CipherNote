# CipherNote

Notes API with JWT Authentication

A secure RESTful Notes API built with Node.js and Express.
This API allows users to create, read, update, and delete (CRUD) notes, with authentication handled via JWT (JSON Web Token).

✨ Features

🔐 JWT Authentication – Secure login and protected routes.

📝 Notes Management – Create, read, update, and delete notes.

👤 User Sessions – Each user can only access their own notes.

⚡ Lightweight & Fast – Simple API design for quick integration.
